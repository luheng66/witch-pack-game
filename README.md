# 女巫背包整理游戏

一个基于HTML5的背包整理小游戏，玩家需要将各种魔法物品整理到背包格子中。

## 游戏特点

- 🎮 简单直观的拖拽操作
- 🧩 多种物品形状和尺寸
- ⭐ 星级评价系统
- 🎯 多关卡挑战
- 🔄 物品旋转功能

## 如何开始

1. 直接在浏览器中打开 `index.html` 文件
2. 或者运行本地服务器：`node static-server.js`
3. 访问 `http://localhost:8080`

## 游戏玩法

1. 拖动物品到背包格子中
2. 按R键或点击旋转按钮来旋转物品
3. 合理安排物品位置以获得更高分数
4. 达到目标分数后点击"出发"按钮

## 技术栈

- 纯HTML5 + CSS3 + JavaScript
- 无需构建工具
- 响应式设计

## 部署

可以部署到任何静态网站托管平台：
- Vercel

- GitHub Pages
